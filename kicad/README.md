# KiCad

KiCad schematic/PCB projects for this project's electronics (e.g. the
analog front-end board described in `../docs/HARDWARE.md`) go here.

Nothing has been designed in KiCad yet - the front end is currently a
breadboard-level reference design. Once it's laid out as a board, commit
the `.kicad_pro`/`.kicad_sch`/`.kicad_pcb` project files (and any custom
symbol/footprint libraries) here.
